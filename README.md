## 📚 Weekly Learning & Assignments

### Week 1 – Data Analytics Fundamentals

| Area | Topics Covered |
|---|---|
| Excel | Data cleaning, formulas, sorting, filtering, pivot tables and dashboards |
| SQL | Database management, querying, filtering, aggregation and data analysis |
| Python for Data Analysis | Python fundamentals, Pandas and data manipulation |
| Data Cleaning & EDA | Data preprocessing, handling missing values and exploratory analysis |
| Data Visualization | Creating dashboards and visual representations of data |
| Statistics | Descriptive statistics and statistical concepts for data analysis |

### Week 2 – Technical Foundations

| Area | Topics Covered |
|---|---|
| Stock Market Fundamentals | Stock market concepts and financial statement analysis |
| REST APIs & JSON | API requests, JSON responses and data extraction |
| Git & GitHub | Version control, repositories, commits and collaboration |
| Software Development Concepts | Foundational software development concepts |
| FinTech Business Understanding | Understanding financial technology and its business applications |
